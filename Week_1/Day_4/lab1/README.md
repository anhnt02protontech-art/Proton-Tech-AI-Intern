# Lab 1 - CSV Processing with Pandas

## Yeu cau
- Python 3.10+ (khuyen nghi)
- Cai thu vien:

```bash
cd Week_1/Day_4/lab1
pip install -r requirements.txt
```

## Cach chay
Chay trong thu muc `Week_1/Day_4/lab1`:

```bash
python lab1.py
```

Hoac chay tu root project:

```bash
python Week_1/Day_4/lab1/lab1.py
```

Neu can doc file CSV khac:

```bash
python lab1.py --file duong_dan_toi_file.csv
```

## Ket qua script
- Doc file `data.csv` va in 5 dong dau tien.
- Loc cac san pham co `Price > 5,000,000`.
- Tinh tong doanh thu theo cong thuc `Price * Quantity` va nhom theo `Category`.
- In ket qua thong ke ra man hinh duoi dang bang.
